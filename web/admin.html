病种库管理

① 按结构分表导入

覆盖＝该区段整表替换；追加/更新＝按序号/编码存在则更新、不存在则新增。导入后立即生效。

立项指南管理

国家医疗服务价格立项指南：整簿 / 分区段导入，项目与使用说明一体维护

① 导入立项指南

支持国家立项指南整簿导入（每个 sheet 一类指南，自动识别首行标题与表头，类别小标题行自动归并为项目类别），或选择单个区段仅导入一张表（首行需含「项目名称」）。
表头识别列：序号｜项目名称｜服务产出｜价格构成｜加收项｜扩展项｜计价单位（计价单元）｜计价说明（使用说明）。
覆盖＝整簿替换同名区段；追加/更新＝按项目名称存在则更新、不存在则新增。

② 解读辅导导入（持续更新）

国家医保局《医疗服务价格项目立项指南解读辅导》文档（支持 .doc / .docx / .wps / .txt），自动按「（第N期）」分册并解析问答条目。
合并更新＝同（期,题号）覆盖、新增追加——新的一期发布后直接上传合并即可；整库替换＝清空现有解读后全量导入。

③ 立项指南明细维护

按指南区段浏览与维护，行内编辑 / 新增 / 删除，使用说明（计价说明）一同维护，改动立即生效并持久化。

① 导入编码对照表

支持列名自动识别：国临版编码 / ICD-10编码 / 诊断编码 / 院内编码｜国临版名称｜医保版2.0编码 / 医保编码｜医保版2.0名称｜灰码（可缺省）。
灰码自动识别：xlsx 中「医保版2.0编码」单元格背景为灰色的行自动标注为灰码；也可用「灰码」列（是/否）；医保编码为空的行同样标灰。
灰码编码不参与映射转换（视为不可用编码），分组时保留原编码并标记。
