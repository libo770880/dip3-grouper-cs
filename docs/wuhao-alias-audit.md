| 检查项 | 数量 | 判定影响 |
|---|---:|---|
| 冗余自名别名 | 100 | 无。条目把自己的主名又列进 alias，HitItem 每条先比主名，结果不变 |
| 跨条目撞名（别名 = 他人主名） | 0 | 若 >0：**清单顺序靠前者胜出**，归属条目 / 分类 / 说明可能串 |
| 别名互撞（同一别名多条目） | 0 | 若 >0：同上 |
| 同名条目 | 0 | 若 >0：判定归属不唯一 |
| 别名撞边界条目 | 3 | 需核对优先级（边界清单在 Judge ② 阶段参与比较）；当前 3 条边界结论同为「不可另收」，无口径冲突 |

> 判定顺序依据 `src/Dip3Grouper.Core/Wuhao.cs` 的 `HitItem`：完全相等阶段按 `Items` 顺序逐条走，
> 每条**先比主名、再比别名**，第一个命中即返回。因此别名与另一条目的主名相同时，索引更小者胜出。
> 两个条目的结论都是「不可另收」，但回显的条目名、分类数、说明会不同。
